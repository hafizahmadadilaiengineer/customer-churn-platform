# 🚀 Customer Churn Intelligence Platform

An end-to-end Machine Learning application that predicts customer churn, explains predictions using Explainable AI, and recommends retention strategies for businesses.

---

## Project Goals

- Predict customer churn
- Explain predictions
- Recommend business actions
- Interactive dashboard
- REST API
- Production-ready deployment

---

## Tech Stack

- Python
- Pandas
- NumPy
- Scikit-Learn
- SHAP
- Plotly
- Streamlit
- FastAPI
- Docker
